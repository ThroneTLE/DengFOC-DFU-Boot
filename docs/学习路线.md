# 学习路线：按工程师的方式用控制理论

本套件 = DengFOC 单路驱动板（STM32F405 + DRV8303）+ 2804 云台电机 + AS5600 编码器。用途：学 FOC；把《自动控制原理》用到实物上；储备系统辨识、无感控制、弱磁等算法。

## 0. 路线的出发点

不按教材章节顺序学，而是照搬做伺服 / 电机驱动的工程师的工作流程，理论在需要时查：

| 工程师的做法 | 含义 | 教材里对应的内容 |
|---|---|---|
| 从指标出发 | 先定带宽、超调、稳态误差、抗扰能力 | 时域指标、稳态误差与系统型别 |
| 对象靠测，不靠推 | 自动辨识 R、L、ψ、J、摩擦；推导只用来核对 | 数学模型、传递函数 |
| 按公式算参数 | 零极点对消、按带宽算 PI，不靠试凑 | 校正设计、PID |
| 串级 + 带宽分离 | 电流环 → 速度环 → 位置环，外环带宽为内环的 1/5–1/10 | 多回路系统 |
| 频域验证 | 扫频测 Bode 图，看穿越频率和相位裕度 | 频域法、稳定裕度（根轨迹工程上少用） |
| 前馈为主，反馈收尾 | 速度、加速度前馈 + 轨迹规划 | 复合控制 |
| 数字化细节 | 采样延迟、滤波器、抗积分饱和、离散化 | 离散系统、Z 变换 |
| 鲁棒性测试 | 换负载、电压、温度，看裕度变化 | 参数灵敏度 |

一个特别的优势：**AS5600 一直能给出真实转角**。做无感算法时，它就是现成的"标准答案"。

## 阶段 1：调试工具（像商用驱动器一样）

工程师的所有工作都建立在这些工具上，所以最先做：

| 工具 | 功能 |
|---|---|
| 内置示波器 | 在控制中断里按控制频率记录多路变量到 RAM，支持触发，记录完上传到电脑 |
| 信号注入 | 在任意一环的给定或输出上叠加阶跃、方波、正弦扫频（chirp）、PRBS |
| 参数辨识命令 | 直流注入测 R；阶跃或交流注入测 L；定速转动测反电动势得 ψ；已知力矩加速测 J；不同转速下测摩擦 |
| 上位机 | 采集、画时域曲线、由扫频数据算 Bode 图、按公式算增益 |
| 电流采样 | DRV8303 放大器 + ADC 注入通道，由 TIM1 在下桥导通时触发（引脚与公式见硬件开发手册 3.2、6.1 节） |

## 阶段 2：电流环（工业 FOC 的起点）

1. **指标**：电流环带宽约为 PWM 频率的 1/20 量级，阶跃无明显超调。
2. **测对象**：用辨识命令测 R、L，与 `电机与编码器参数.md` 的 2.55 Ω、0.9 mH 核对。
3. **算参数**：零极点对消，Kp = L·ωc，Ki = R·ωc。
4. **验证**：电流阶跃看上升时间；扫频看带宽和相位裕度；加 ωL 交叉解耦和反电动势前馈，对比效果。
5. **对比**：同一台电机，电压型 FOC 和电流型 FOC 的力矩线性度、响应速度有什么差别。

## 阶段 3：速度环

1. **指标**：带宽为电流环的 1/5–1/10，定出阶跃超调和负载扰动下的速度跌落。
2. **测对象**：辨识 J 和摩擦（库仑 + 粘滞），与模型 τm ≈ 10.5 ms 核对。
3. **算参数**：Kp = J·ωc / Kt，积分零点放在穿越频率以下约 4 倍处；速度反馈低通滤波的截止频率要留出相位裕度。
4. **验证**：速度阶跃、加扰动（手拧或加负载）、闭环扫频看裕度。
5. **改进**：加速度前馈、抗积分饱和，对比前后数据。

## 阶段 4：位置环与轨迹

1. P（或 PI）位置环，带宽为速度环的 1/3–1/5；
2. 梯形 / S 曲线轨迹规划 + 速度、加速度前馈；
3. 指标：跟踪误差、定位时间、到位后的抖动；
4. 鲁棒性：加负载惯量，看同一套参数的裕度怎么变，必要时做增益调度。

## 阶段 5：无感 FOC（算法储备）

按工程上开发无感的方法：

1. **影子模式**：电机仍由编码器闭环控制，观测器在后台同时运行，只算不用；
2. 观测器：反电动势观测器（滑模、龙伯格）+ 锁相环；磁链观测器（VESC 用的那类）；
3. 用 AS5600 算角度估计误差随转速的变化，找到低速失效边界；
4. 误差达标后再切换：开环 I/f 启动 → 观测器收敛 → 切到无感闭环；
5. 说明：表贴式电机几乎没有凸极性，零速高频注入（HFI）很难成功。

## 阶段 6：弱磁（算法储备）

1. 先测出电压饱和点：Uq 接近 Vbus/√3 时的转速（12 V 下约 283 rad/s）；
2. 电压反馈型弱磁：电压接近极限时自动给负 id；
3. 测转速 - 转矩曲线，对比有无弱磁；
4. 这台电机特征电流 ψf/Ld ≈ 3.9 A 大于 2 A 上限，弱磁区有限；用 7.4 V 电源降低基速更容易观察；
5. 注意弱磁失控时反电动势会超过母线电压，用电池供电让回馈能量有处可去。

## 阶段 7：可选课题

齿槽力矩补偿、陷波滤波器、扰动观测器（DOB）、自动整定（auto-tuning）、在线参数辨识、模型预测控制（MPC）。
