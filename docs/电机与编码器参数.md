## 2. 推导量（建模起点，待实验辨识修正）

本套件的固件用幅值不变的 Clarke/Park 变换，所以：

| 量 | 公式 | 数值 |
|---|---|---|
| 力矩常数（dq） | Kt = 1.5 · p · ψf | **0.0368 N·m/A** |
| 电气时间常数 | τe = Ls / Rs | **0.35 ms**（极点约 450 Hz） |
| 速度电压常数 | p · ψf | 0.0245 V/(rad/s) |
| 电压→空载转速增益 | 1 / (p · ψf) | **40.8 (rad/s)/V** |
| 机械时间常数（只算转子） | τm = Rs · J / (Kt · p · ψf) | **≈ 10.5 ms** |
| 12 V 时最大相电压幅值 | Vbus / √3 | 6.93 V |
| 12 V 空载最高转速 | 6.93 × 40.8 | ≈ 283 rad/s ≈ 2700 rpm（厂家 2600 rpm） |

### 电压型 FOC 的速度模型

忽略电感（τe ≪ τm）、令 id = 0：

```
uq = Rs·iq + p·ψf·ω
J·dω/dt = Kt·iq − B·ω − T_load
```

消去 iq，得到 uq → ω 的一阶惯性环节：

```
G(s) = ω(s) / Uq(s) = K / (τm·s + 1)
K  = Kt / (Kt·p·ψf + Rs·B) ≈ 1 / (p·ψf) = 40.8 (rad/s)/V     （B ≈ 0 时）
τm = Rs·J / (Kt·p·ψf + Rs·B) ≈ 10.5 ms
```

这个模型没有算进去的东西：库仑摩擦和齿槽力矩（低速时明显）、AS5600 的滤波延迟、2 kHz 采样和计算延迟、负载惯量。这些正是系统辨识实验要测出来的。

### 与实测的初步对照（2026-10-20，空载）

| 工况 | 模型预测 | 实测 |
|---|---|---|
| 维持 5 rad/s 所需 Uq | 5 / 40.8 ≈ 0.12 V | ≈ 0.2 V（差值主要是摩擦） |
| 12 V 空载转速 | ≈ 2700 rpm | 未测（厂家 2600 rpm） |

## 3. 弱磁相关的量

| 量 | 公式 | 数值 |
|---|---|---|
| 特征电流 | ψf / Ld | 0.0035 / 0.0009 ≈ **3.9 A** |
| 电流上限 | — | 2 A |

特征电流大于电流上限，说明这台电机只能做有限的弱磁扩速，无法做到"无限转速"区。弱磁实验建议降低母线电压（如 7.4 V），让基速落到容易观察的范围。

## 4. AS5600 磁编码器模块

| 项目 | 值 |
|---|---|
| 分辨率 | 12 位，4096 计数/圈（0.088°） |
| 接口 | P1：I²C（VCC / GND / SCL / SDA）；P2：模拟或 PWM（OUT / PGO / GND / VCC） |
| 供电 | 默认 3.3 V（断开 R6 可用 5 V） |
| 方向 | 默认顺时针增加（R4 改焊到 R3 变为逆时针） |
| I²C 地址 | 0x36 |
| 常用寄存器 | CONF 0x07/0x08、STATUS 0x0B、RAW ANGLE 0x0C/0x0D、AGC 0x1A、MAGNITUDE 0x1B/0x1C |
| 固件设置 | 慢速滤波 SF = 2×（最快、噪声最大），快速滤波关闭；只写易失寄存器，从不烧录 |

### 在本套件上的接法与实测

| 项目 | 值 |
|---|---|
| 接线 | VCC → 排针"3"，GND → "G"，SCL → Pin3（PA2），SDA → Pin4（PA3） |
| I²C | 排针 GPIO 软件模拟，按实测上升时间自动定速 |
| 读一次角度 | 119 µs（RAW ANGLE 免指针连续读） |
| 磁场 | STATUS 报"偏弱"，AGC = 128（3.3 V 下的最大值），MAGNITUDE ≈ 1150；已贴到机械极限 |
| 静止噪声 | < 0.1°，速度噪声约 0.01 rad/s（10 ms 低通后） |
