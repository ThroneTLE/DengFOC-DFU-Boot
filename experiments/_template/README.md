## 1. 指标

这一步要达到什么，写成可以测量的数：带宽、超调、调节时间、稳态误差、扰动下的跌落等。

## 2. 对象（实测）

被控对象的参数从哪来：辨识命令测得的值、之前实验的结果。与 `docs/电机与编码器参数.md` 的理论值对比，差别大的要先找原因。

## 3. 设计（计算）

由指标和对象参数算出控制器参数，写出公式和代入的数，例如 Kp = L·ωc。同时写出预测的响应。

## 4. 验证

具体命令、记录的数据（放在 `data/`），以及结果：时域曲线（阶跃）、频域曲线（扫频 Bode 图）、裕度。和第 1、3 节逐项对比。

```
python tools/dengfoc_cli.py cal
python tools/dengfoc_cli.py "ulim 2" "vel 5" "mon 3" stop
```

## 5. 结论与下一步

是否达标；没达标的原因（模型误差、延迟、饱和、噪声）；下一步改什么。
