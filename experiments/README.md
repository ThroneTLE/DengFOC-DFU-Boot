# 实验记录

每个实验一个文件夹，名字用 `日期_主题`，例如 `2026-10-21_速度阶跃响应`。复制 [_template](_template) 开始。

```
2026-10-21_速度阶跃响应/
├── README.md      指标、对象、设计、验证、结论
├── data/          原始数据（CSV），不要手改
└── analysis/      分析脚本（.py / .ipynb）和生成的图
```

约定：

- **按工程流程写：指标 → 实测对象 → 计算设计 → 验证。** 先写指标和计算出的预测，再做实物，最后逐项对比，差异本身就是收获。
- 写清楚用的固件和版本（应用名 + 编译日期，或 git 提交号），以及所有改过的参数（`ulim`、`vpi` 等）。
- 原始数据只追加不修改，处理后的数据放进 `analysis/`。
