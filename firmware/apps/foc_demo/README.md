# FOC demo：2804 云台电机 + AS5600

电压型 FOC（不用电流环），适用于高电阻云台电机。电机参数：2804、12N14P（7 对极）、相电阻 2.55 Ω、额定 0.5 A、最大 2 A、7.4–16 V。

## 接线

| AS5600 模块 P1（I²C） | DengFOC 2×7 排针 |
|---|---|
| VCC | "3"（数字 3.3 V） |
| GND | "G" |
| SCL | Pin3（接 Pin1–Pin7 任意两根都行，上电自动扫描） |
| SDA | Pin4 |

- 电机三相 → MR30 电机输出口，相序任意（校准时自动识别方向）。
- 12 V 电池 → XT30 电源口，注意正负极。建议串一个 3–5 A 保险丝。
- 编码器必须和电机定子固定在一起，磁铁对准芯片，间距 1–3 mm；电机要固定住。

## 编译与烧录

```
bash build.sh
STM32_Programmer_CLI -c port=USB1 -w build/foc_demo.bin 0x08008000 -v -s 0x08008000
python ../../../tools/dengfoc_cli.py enc
```

板子正在运行其它程序时，先发 `dfu` 让它回到 USB 烧录模式。

## 命令

| 命令 | 作用 |
|---|---|
| `enc` | 编码器所在针脚、读取耗时、角度、磁铁状态 |
| `detect` | 重新扫描 AS5600 |
| `s` / `mon [秒]` | 一次 / 每 0.1 秒打印状态 |
| `open <rad/s>` | 开环旋转（不用编码器），用来先检查功率级 |
| `cal` | 校准：识别转向、核对极对数、找电角度零位 |
| `tq <V>` | 力矩模式（直接给 Uq） |
| `vel <rad/s>` | 速度模式 |
| `pos <deg>` | 位置模式（相对 `cal` 或 `zero` 时的位置） |
| `zero` | 把当前位置设为 0°；旋钮模式下同时设为第 0 档 |
| `knob <n>` | 力反馈旋钮，41 个预设（`knob` 不带参数列出全部，见 [实验记录](../../../experiments/2026-10-20_力反馈旋钮/README.md#32-41-个预设)）；`knob 0` 停止。`knob <n> <度>` 让格中心偏开一段再启动，用来测回位；电机在转时切换会保留惯性 |
| `kstr <x>` | 旋钮手感力度，0–3，默认 1 |
| `kcomp <c0+> <c0-> <c1>` | 自由、飞轮类的对象补偿（摩擦 V、反电动势 V/(rad/s)），由 `tools/ident_friction.py` 测出 |
| `stop` | 关闭输出并拉低 EN_GATE |
| `ulim <V>` | 电压上限，默认 2 V，最大 5 V（≈2 A 堵转） |
| `vlim <rad/s>` | 位置模式的速度上限，默认 30 |
| `vpi <P> <I>` | 速度环参数，默认 0.1 / 2.0；`vp <P>`、`vi <I>` 单独改一个 |
| `ap <P>` | 位置环比例，默认 20 |
| `pp <n>` | 极对数，默认 7 |
| `scope [hz]` / `scope 1` | 开始推送波形（VOFA+ JustFloat，默认 2 kHz），期间暂停文字回复 |
| `scope off` / `scope 0` | 停止推送，报告丢帧数 |
| `act <n>` | 上位机按钮用：0 停止、1 校准、2 清故障、3 归零 |
| `clear` | 清除故障 |
| `dfu` | 回到 USB 烧录模式 |

## 实时波形

固件在控制中断里每个周期（2 kHz）记录 14 个通道，主循环按 VOFA+ JustFloat 格式（14 个 float + 帧尾 `00 00 80 7F`）通过 USB 推送。实测 2003 帧/秒，丢帧 0。

| 通道 | Synex 名称 | 含义 |
|---|---|---|
| 0 | 目标 | 当前模式的目标值（位置模式为度；旋钮模式为当前格中心，度） |
| 1 | 位置_deg | 机械角度，° |
| 2 | 速度_rad_s | 实测速度 |
| 3 | 速度参考 | 速度环输入 |
| 4 | Uq_V | q 轴电压 |
| 5 | 电角度_rad | θe |
| 6 | 母线_V | 母线电压 |
| 7 | 中断_us | 控制中断耗时 |
| 8 | 模式 | 0 停止、1 校准中、2 开环、3 力矩、4 速度、5 位置、6 旋钮 |
| 9 | 故障 | 0 正常、1 DRV 故障、2 编码器、3 母线电压、4 过温、5 DRV 配置 |
| 10 | MOS温度_C | MOS 管温度，°C |
| 11 | 已校准 | 0 / 1 |
| 12 | 旋钮档位 | 当前格的编号 |
| 13 | 旋钮模式 | 旋钮预设 1–8，不在旋钮模式时为 0 |

旋钮的设计、参数和实测见 [experiments/2026-10-20_力反馈旋钮](../../../experiments/2026-10-20_力反馈旋钮/README.md)。

三种看法（串口一次只能被一个程序打开）：

1. **Synex**（`E:\User\Desk\Synex_v3.0.5`）：已配好"DengFOC 电机"页，连接 COM 口后点"遥测数据流"开关即可，见 [tools/synex/README.md](../../../tools/synex/README.md)。**VOFA+**：连接 COM 口、协议选 JustFloat、12 个通道，在发送框发 `scope 1`（带换行）。
2. **采集成 CSV**（做实验用）：
   ```
   python tools/scope_capture.py --seconds 4 --cmd "vel 5" --cmd "@2 vel -5" --cmd "@3.5 stop" --out run.csv
   ```
3. 停止推送：`python tools/dengfoc_cli.py "scope off"`。

## 保护

- 上电后所有栅极输入、EN_GATE、刹车 AUX_H/AUX_L 都是低电平；只有运动命令才会启用。
- 母线电压不在 9–16.8 V 时拒绝启动，运行中越限立即停机。
- DRV8303 设为过流锁存关断（Vds 阈值最低档），nFAULT 拉低立即停机。
- 闭环模式下编码器连续 20 次读取失败、MOS 温度超过 80 °C 时停机。
- PWM：24 kHz 中心对齐，死区 119 ns，占空比限制在 5%–95%。

## 实现

| 文件 | 内容 |
|---|---|
| `Core/Src/as5600.c` | 排针上的软件 I²C，自动找 SCL/SDA，按实测上升时间选速率 |
| `Core/Src/drv8303.c` | SPI3 读写 DRV8303 |
| `Core/Src/foc.c` | TIM1 PWM、TIM7 控制中断（2 kHz 或 1 kHz）、SVPWM、速度/位置环 |
| `Core/Src/main.c` | 初始化、保护、校准、命令行 |

## 实测记录（2026-10-20，12 V 电池 11.78 V，空载，电压上限 2 V）

| 步骤 | 结果 |
|---|---|
| 编码器 | 自动定位 SCL = Pin3（PA2）、SDA = Pin4（PA3）；读一次 119 µs；控制环 2 kHz，中断 123–134 µs；磁场标志"偏弱"（AGC 128），但静止抖动 < 0.1° |
| `open 3` | 测得 2.86–2.98 rad/s，与命令一致 |
| `cal` | 一个电周期转 51.1°（理论 51.4°），极对数 7.05，往返误差 0.4°，dir = +1 |
| `vel 5` / `vel -5` | 4.65–5.21 / −4.87 – −5.17 rad/s，Uq ≈ 0.2 V |
| `pos 0/90/-90/0` | 0.0° / 90.0° / −90.0° / 0.0°，180° 跳转 < 0.5 s 到位，误差 ≤ 0.1° |
| 保护 | 全程 0 次编码器错误、无故障；MOS 35.0 → 35.6 °C |

每次上电都要重新 `cal`（零位没有存进 Flash）。
